# 日本全国旅行ガイド

ももした道場のGit・GitHub入門実習で作る、全国の旅行アイデア集です。
**個人で一県、チームで一地方、全体で一つのリポジトリ**を使います。

## 実習の進め方
- [参加者向け手順](参加者向け手順.md)を読み、AIへ一段階ずつ操作を頼みます。
- 編集するのは自分が担当する県のファイル一つだけです。
- 自分の作業ブランチからmainへPRを出します。mainへ直接pushしません。
- チームの支援者に確認してもらい、マージ担当者が順次取り込みます。
- 各県のファイルは準備用のひな形です。「未記入」を自分のプランに置き換えてください。
- 全47都道府県を用意していますが、当日にすべて埋めることは必須ではありません。
- 旅行プランは練習用のアイデアです。実際の旅行に使う際は、営業情報や交通情報を別途確認してください。
